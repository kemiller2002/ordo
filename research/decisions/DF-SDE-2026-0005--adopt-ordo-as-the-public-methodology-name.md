# DF-SDE-2026-0005

## Context

A repository-external instruction directed this repository to build a public
website for **Ordo**, described as "Echelon Foundry's State-Directed
Engineering methodology."

A discovery pass over this repository found a direct conflict with that
framing, which is recorded here rather than resolved silently:

- The string `Ordo` appears **zero** times in this repository at commit
  `fd446d4fa797bacde3fcc4eec6f47e4b114c396d` (verified by
  `grep -ril "ordo" --exclude-dir=.git .`, no matches).
- Every authoritative record — `PROJECT-CHARTER.md`,
  `doctrine/STATE-DIRECTED-ENGINEERING.md`, `DF-SDE-2026-0001`,
  `method/CONSTRUCTION-METHOD-v0.2.md`, the published npm package
  `@echelon-foundry/sde` — names the methodology **State-Directed
  Engineering (SDE)**.
- No `Limen` artifact, configuration, or documentation exists in this
  repository or in any of the five evidence repositories inspected for the
  website build (see `site/README.md`, "Repositories inspected").

## Decision

1. **Ordo is the public-facing name of the methodology.** New public
   documentation — specifically the website under `site/` — uses *Ordo*.
   `AGENTS.md`'s authority order places explicit user instruction above
   canonical governance, and the instruction was explicit and unambiguous on
   this point.

2. **State-Directed Engineering remains the name used in the research
   record.** No `research/`, `doctrine/`, `method/`, `framework/`,
   `registries/`, `templates/`, `src/`, or `distribution/` artifact is
   renamed, and no historical identifier (`EV-`, `HY-`, `TH-`, `DF-`,
   `RP-`, `JR-`, `SDE-DOCTRINE-*`) changes. Experimental artifacts are part
   of the experimental record; renaming them would break provenance for
   every metric the website cites.

3. **The relationship is stated explicitly wherever both names appear.**
   Ordo *is* the methodology this repository develops under the name
   State-Directed Engineering. They are not two methodologies, two versions,
   or a rebrand that changes content. The website's `/about/` page and its
   glossary both carry this statement.

4. **No claim is made about Limen.** Because no Limen artifact was found in
   any accessible repository, the website makes no statement about what
   Limen is, what it does, or how Ordo relates to it, beyond recording that
   it was looked for and not found. Describing an unexamined component would
   violate `framework/policies/EVIDENCE-POLICY.md` and this repository's
   no-fabrication rule.

5. **ROS is described only as this repository actually uses it** — as the
   Repository Operating System that governs work items, artifact lifecycle,
   evidence records, and validation (`AGENTS.md`, `ros.json`,
   `docs/00-governance/`). No broader "engineering execution environment"
   capability is claimed on its behalf.

## Alternatives considered

- **Rename everything to Ordo, repository-wide.** Rejected. It would
  invalidate the provenance chain from every published metric back to the
  `EV-`/`HY-`/`TH-` record that produced it, contradict
  `framework/protocols/SUPERSESSION.md`, and rewrite artifacts whose names
  are themselves part of the experimental record.
- **Ignore the Ordo name and publish the site as "SDE".** Rejected: the
  instruction to use Ordo publicly was explicit, and `AGENTS.md` ranks
  explicit user instruction above canonical governance.
- **Treat Ordo and SDE as distinct concepts (as State Programming and SDE
  are distinct).** Rejected: nothing in the instruction or in any inspected
  repository describes a substantive difference between them. Inventing a
  distinction would be fabrication. They are one methodology under two
  names, and the site says so.

## Consequences

- The website is authored under `site/` and generated by `src/Ordo.Site`.
  Its content uses *Ordo*; every citation it renders points at an
  SDE-named artifact, and the site tells the reader why.
- `doctrine/`, `method/` and `research/` are unchanged by this decision.
  A future decision may rename them; this one does not.
- Anyone encountering "SDE" in a cited artifact and "Ordo" on the site can
  resolve the difference from `/about/` or `/glossary/` without asking.

## Confidence

This is a scoping and naming decision, not an empirical claim. It carries
no confidence class in `doctrine/EVIDENCE-TO-ENGINEERING-MAP.md` and adds
no row to it.
