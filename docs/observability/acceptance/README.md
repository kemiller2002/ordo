# ORDO-OBS-001 acceptance output

Generated by `scripts/ordo-events-acceptance.sh` from this repository's
`tests/fixtures/construction/time-entry-timer` cohort (`COH-TIMER`). This is
**fixture data, not rehearsal data**: no Indy Init rehearsal recorded a
pattern recognition (see `../rehearsal-evidence-matrix.md`).

| file | origin |
|---|---|
| `decision-events.jsonl` | real `sde ecir recognize --events` output for two recognitions (with and without approved decision records), plus one `agent.execution` and one `verification.result` |
| `recognition-*.txt` | the recognitions' unchanged stdout |
| `approvals.json` | operator approvals used by the first recognition |
| `dokimos-receipt.json` | **hand-written**, in the shape of `dokimos.completion-verification`, with verdict `rejected`. It exercises the "executed, then failed verification" path. It is not output of a Dokimos run |
| `decision-summary.json` | `sde events summarize --json` over the log |

The execution event is reported by the acceptance script itself
(`--executor acceptance-script`); nothing was executed.

Rerun: `scripts/ordo-events-acceptance.sh` (event ids, timestamps and
durations change on every run; decision ids and counts do not).
